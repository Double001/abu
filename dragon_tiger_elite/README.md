# 龙虎榜精选模式

A股龙虎榜超短线策略 — 精选模式

## 策略表现

| 指标 | 结果 |
|------|------|
| 回测区间 | 2024-2025 (50只A股活跃股) |
| 胜率 | **94%** |
| 盈利均值 | **+43%** |
| 交易频率 | ~8笔/年 |

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 实时扫描今日信号
python run.py

# 回测历史数据
python run.py --backtest
```

## 策略规则

**入场条件 (全部满足):**
1. 个股当日涨幅 ≥ 7%
2. 成交量 ≥ 20日均量 × 2
3. 3日市场热度 ≥ 5只股票同涨
4. 上证5日涨幅 ≥ 1%
5. 近3天无连续涨停 (排除疲劳)
6. 个股情绪得分 ≥ 55
7. 次日跳空 < 5% (排除高开陷阱)

**卖出规则:**
- 追踪止盈: 峰值≥20%后回撤8%
- 到期止盈: 持仓≥60天且盈利
- 强制平仓: 持仓≥90天
- 硬止损: 浮亏≥20%
